# Arbeidstijden Tracker — Installatie-instructies

## Stap 1 — GitHub account aanmaken
1. Ga naar **github.com**
2. Klik op **Sign up**
3. Kies een gebruikersnaam (bijv. `jeroen123`), vul e-mail en wachtwoord in
4. Bevestig je e-mailadres

---

## Stap 2 — Nieuw repository aanmaken
1. Klik rechtsboven op het **+** icoontje → **New repository**
2. Geef het de naam: `arbeidstijden`
3. Zet op **Public** (verplicht voor gratis GitHub Pages)
4. Klik op **Create repository**

---

## Stap 3 — Bestanden uploaden
1. Klik op **uploading an existing file** (of **Add file → Upload files**)
2. Sleep alle bestanden uit deze map naar het uploadvenster:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. Scroll naar beneden → klik **Commit changes**

---

## Stap 4 — GitHub Pages inschakelen
1. Klik op **Settings** (tandwieltje bovenaan je repository)
2. Scroll in het linkermenu naar **Pages**
3. Onder **Source**: kies **Deploy from a branch**
4. Onder **Branch**: kies **main** → klik **Save**
5. Wacht 1-2 minuten

Je tracker is nu bereikbaar op:
**`https://JOUWNAAM.github.io/arbeidstijden`**

---

## Stap 5 — App installeren op je telefoon

### iPhone (Safari)
1. Open de link in **Safari**
2. Tik op het **Deel-icoontje** (vierkantje met pijltje omhoog)
3. Scroll naar beneden → **Zet op beginscherm**
4. Geef de app een naam → **Voeg toe**

### Android (Chrome)
1. Open de link in **Chrome**
2. Tik op de **drie puntjes** rechtsbovenin
3. Tik op **Toevoegen aan startscherm**
4. Bevestigen

De app staat nu als icoontje op je beginscherm en opent zonder adresbalk!

---

## Bijwerken na een update
1. Ga naar je repository op github.com
2. Klik op het bestand dat je wilt vervangen → **het potlood-icoontje** (Edit)
   — of sleep een nieuw bestand over het oude heen via **Add file → Upload files**
3. Klik **Commit changes**
4. Na 1-2 minuten is de update live. Ververs de app op je telefoon.
